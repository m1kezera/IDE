### 6. Aprenda com Exemplos:
Aqui está um exemplo básico usando Scapy para capturar e modificar pacotes:

```python
from scapy.all import *

def sniff_and_hijack(interface):
    # Configuração básica do pacote alvo
    victim_ip = "192.168.1.1"

    # Escaneia por pacotes na interface especificada (ex.: eth0)
    packets = sniff(iface=interface, count=100)

    for packet in packets:
        if IP in packet and packet[IP].dst == victim_ip:
            print("Pacote capturado para o destino", victim_ip)
            # Modificar o destino do pacote
            packet[IP].dst = "192.168.1.2"
            send(packet, iface=interface)

if __name__ == "__main__":
    interface = input("Qual a sua interface de rede? ")
    sniff_and_hijack(interface)
```

### Criação de uma Dashboard Simples com Python

Vou criar uma simples interface gráfica de usuário (GUI) usando `tkinter`, um módulo padrão do Python. Essa GUI permitirá que você interaja com a funcionalidade de captura e modificação de pacotes de rede usando Scapy, de forma mais controlada e segura.

#### Etapa 1: Instalando Dependências

#### Etapa 2: Criando a Interface Gráfica

Aqui está um exemplo básico de como criar uma interface gráfica com tkinter e integrar a funcionalidade de Scapy.

```python
import tkinter as tk
from tkinter import ttk
from scapy.all import *

class HijackApp:
    def __init__(self, master):
        self.master = master
        self.master.title("Hijacker Dashboard")
        
        # Define os frames e widgets da interface
        self.top_frame = ttk.Frame(master)
        self.bottom_frame = ttk.Frame(master)

        # Botão para iniciar a captura de pacotes
        self.start_button = ttk.Button(self.top_frame, text="Start Capturing", command=self.start_capture)
        self.start_button.pack(side=tk.LEFT)

        # Lista para exibir os pacotes capturados
        self.packets_listbox = tk.Listbox(self.bottom_frame, height=15, width=50)
        self.packets_listbox.pack()

        # Configurações iniciais
        master.resizable(False, False)
        master.grab_set()
        master.mainloop()

    def start_capture(self):
        # Seta a interface padrão para capturar pacotes (deixe como está para a maioria das configurações de rede)
        interface = "eth0"  # Altere isso se necessário

        # Inicia a captura e modificação dos pacotes
        packets = sniff(iface=interface, count=100)
        
        # Loop através dos pacotes capturados e exibe na listbox
        for packet in packets:
            if IP in packet:
                dst_ip = packet[IP].dst
                print(f"Capturado pacote com destino: {dst_ip}")
                self.packets_listbox.insert(tk.END, f"Pacote capturado ({dst_ip})")

if __name__ == "__main__":
    root = tk.Tk()
    app = HijackApp(root)
```

- **Captura de Pacotes:** Ao pressionar o botão, começa a captura de pacotes na rede usando `scapy`. Esses pacotes podem ser visualizados na listbox.

#### Conclusão:

Este exemplo é apenas uma introdução para criar uma interface gráfica em Python que interaja com a funcionalidade de `scapy` para capturar e modificar pacotes.
